# Contributing to awesome-ai-visibility

Thanks for contributing! This is a curated list, so quality over quantity.

## Entry Criteria

- Must be directly relevant to AI visibility / GEO / AEO / AI search optimization
- Must have a clear one-line description
- Tools must be actively maintained (updated within 12 months)
- Research papers must be published or accepted at a recognized venue
- No affiliate links, no paid listings

## How to Contribute

1. Open a pull request with your addition
2. Add your entry in the appropriate category, maintaining alphabetical order
3. Follow the existing format: `[Name](URL) - Description.`
4. Briefly explain why this belongs in the list

## Format

```markdown
- [Name of Resource](https://example.com) - One-line description of what it is and why it matters.
```

## Code of Conduct

Be respectful. This is a community resource. Spam, self-promotion without value, and disrespectful behavior will result in PR closure.
